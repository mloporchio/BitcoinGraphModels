# Bitcoin Graph Models

This repository contains code for the paper *"Systematizing Graph Models for Bitcoin and Designing Algorithms for Large-Distance
Analysis"* by Anna Bernasconi, Damiano Di Francesco Maesa, Matteo Loporchio, Andrea Marino, Massimo Nocentini, and Laura Ricci.

The paper is currently under review and the code is provided here for reproducibility purposes. The code is organized in the following folders:
- `data`: contains the data used for the experiments
- `src`: contains the source code for the algorithms and the experiments
- `ag`: 

## Data availability

The data used for the experiments is available in the `data` folder. The data is in CSV format and contains the following files:
- `transactions.csv`: contains the transactions data
- `blocks.csv`: contains the blocks data
- `addresses.csv`: contains the addresses data
